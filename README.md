# 2025-2026-CSP-
All the code I made during AP CSP
This Python program was created as part of an AP Computer Science Principles course to showcase fundamental computing concepts. The code uses procedural abstraction, algorithmic thinking, and data processing to build a functional and easy‑to‑understand application. The goal is to demonstrate how simple algorithms and clean design can be combined to solve a problem efficiently.

Key Features
User Input Handling — The program collects and validates user input to ensure smooth interaction.

Variables and Data Types — Stores and manipulates information using integers, strings, lists, and booleans.

Conditional Logic — Uses if/elif/else statements to make decisions based on user data.

Loops and Iteration — Repeats tasks efficiently using for and/or while loops.

Functions for Abstraction — Breaks the program into smaller, reusable components to improve readability and reduce repetition.

Output Formatting — Presents results clearly using formatted strings and structured print statements.
